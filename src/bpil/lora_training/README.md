## Training

The training scripts are designed to be reusable across all supported LLMs. To train a different model, only the model-specific names and paths need to be adjusted accordingly.

Supervised fine-tuning (SFT) was performed using **LLaMA-Factory** (https://github.com/hiyouga/LlamaFactory).

For instructions on setting up the environment, configuring datasets, and running SFT, please refer to the official LLaMA-Factory documentation (https://llamafactory.readthedocs.io/en/latest/getting_started/sft.html).
